Connect an AI agent

Point a compatible MCP client at GitHired to search real Canada-eligible tech jobs with original employer apply links.

Three ways to use GitHired

  1. Website search — browse filters on githired.ca.
  2. REST API — HTTP JSON for your own tools (docs).
  3. MCP — tool calling for AI assistants (this page).

Publishing an MCP server does not guarantee automatic discovery by ChatGPT or Claude. You (or the product) must configure the connector URL.

MCP endpoint

https://api.githired.ca/mcp

Transport: Streamable HTTP (JSON-RPC). No API key required for normal use.

Tools

  • search_jobs — keywords, location, province, remote, salary floor, seniority, company
  • get_job — detail by GitHired id
  • match_profile — deterministic skill/role matching (profiles are not stored)
  • get_market_stats — aggregates for tracked employers only
