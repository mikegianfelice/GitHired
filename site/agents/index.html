MCP · Free · No account · Read-only

Give your AI agent access to Canadian tech jobs

Connect Cursor, Claude, ChatGPT, or any MCP-compatible client to GitHired’s live Canada-eligible job dataset — original employer apply links, advertised salaries only, no résumé upload.

Connect to Cursor REST API docs

The Cursor button uses Cursor’s official MCP install deeplink (cursor://anysphere.cursor-deeplink/mcp/install). Cursor prompts before installing. No authentication is required for GitHired.

MCP endpoint

https://api.githired.ca/mcp

Transport: Streamable HTTP (JSON-RPC). Protocol: 2024-11-05.

Installation

Cursor (one-click)

  1. Click Connect to Cursor above (or paste the deeplink into your browser).
  2. Approve the install prompt in Cursor.
  3. Ask Cursor something like the example prompts below.

Manual config (~/.cursor/mcp.json or project .cursor/mcp.json):

{
  "mcpServers": {
    "githired": {
      "url": "https://api.githired.ca/mcp"
    }
  }
}

Claude (custom connector)

Claude supports remote MCP via Connectors → Add → Custom → Web (Claude.ai / Desktop). There is no official public one-click install URL for third-party servers — paste the endpoint and choose No sign in.

  1. Open Customize → Connectors → Add → Custom → Web.
  2. Name: GitHired
  3. URL: https://api.githired.ca/mcp
  4. Authentication: No sign in

ChatGPT (custom MCP plugin)

ChatGPT supports remote MCP plugins on the web. There is no official third-party one-click install link — add a custom server and install the plugin.

  1. Open chatgpt.com/plugins → Add custom MCP server.
  2. Server URL: https://api.githired.ca/mcp
  3. Authentication: No authentication
  4. Create as a plugin, then install it and mention it with @ in chat.

Tools

search_jobs

Keywords, location, province, remote, work mode, minimum CAD salary, seniority, company, limit (≤25).

get_job

Full detail for a stable GitHired id, including description excerpt and apply URL.

match_profile

Deterministic skill/role matching. Profiles are not stored. Scores are relevance, not hiring decisions.

get_market_stats

Aggregates for tracked employer ATS boards only — not a full labour-market census.

Example prompts

Find five remote Senior Data Engineer jobs available in Canada.
Find Toronto software engineering roles advertising at least CAD $150,000.
Match me to data engineering jobs: Python 5y, SQL 5y, Databricks 2y, ETL, cloud.
Show Canadian tech job market stats from GitHired's tracked employers.

Example tool call

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "search_jobs",
    "arguments": {
      "keywords": "data engineer",
      "remote": true,
      "minimum_salary": 150000,
      "limit": 5
    }
  }
}

Troubleshooting

  • Cursor deeplink does nothing — update Cursor, or paste the JSON config into ~/.cursor/mcp.json and reload MCP.
  • Tools missing — confirm the server shows as connected in MCP settings; retry initialize / refresh tools.
  • Empty results — broaden keywords; salary filters only match employer-advertised annual base.
  • HTTP 429 — slow down; limit is about 120 requests/minute/IP.
  • Stale data — check the status pill above or GET /api/v1/health. Freshness threshold is 48 hours.
  • Inspector — npx @modelcontextprotocol/inspector https://api.githired.ca/mcp

Safety & limits

  • Read-only — no apply automation
  • No résumé or personal profile persistence
  • Canada-first eligibility; never invents geography or pay
  • Public REST twin: /developers
