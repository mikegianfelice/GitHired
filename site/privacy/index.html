Privacy

Last updated: 2026-11-24. This page describes how the public GitHired website, REST API, and remote MCP server handle information. It is factual product documentation, not legal advice.

Summary

  • No account is required to browse jobs, call the public API, or use the MCP server.
  • The browser-side “Find my matches” flow keeps résumé text in your browser; GitHired does not upload or store résumés for that tool.
  • MCP match_profile requests are processed ephemerally and are not used to build a résumé archive.
  • Job data comes from public employer ATS boards. Apply links go to the employer.

What we collect

  • Request logs / rate limits: standard HTTP metadata (such as IP address, user agent, path, and timestamps) may be processed by our hosting providers to operate the service and enforce per-IP rate limits.
  • Cloudflare Web Analytics: the marketing site uses Cloudflare Web Analytics, which is cookieless and does not track individuals, to count visits and which /from/ attribution link people arrived from.
  • Public job dataset: listings and employer metadata scraped from public career/ATS pages.

What we do not do

  • We do not sell personal data.
  • We do not auto-apply to jobs on your behalf.
  • We do not invent salaries or Canadian work eligibility.
  • We do not require OAuth or API keys for normal public use.

Third parties

Hosting, DNS, and CDN providers process requests necessary to serve https://githired.ca and https://api.githired.ca. Employers receive applications only if you apply on their sites.

Contact

Questions or privacy requests: open an issue on the public repository github.com/mikegianfelice/GitHired/issues.
