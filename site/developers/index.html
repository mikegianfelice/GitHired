GitHired REST API

Query Canada-eligible technology jobs discovered from employer ATS boards. Free HTTPS JSON. No authentication for normal search traffic.

Quick start

curl -sS 'https://api.githired.ca/api/v1/jobs?q=data%20engineer&remote=true&salary_min=150000&limit=5' | jq .

Pagination

  1. Call /api/v1/jobs with limit.
  2. If next_cursor is non-null, pass it as cursor on the next request.
  3. Stop when next_cursor is null.
curl -sS 'https://api.githired.ca/api/v1/jobs?q=engineer&limit=20&cursor=Mg==' | jq '.next_cursor,.jobs|length'

total is the full match count before pagination. Cursors are opaque — do not invent them.

Salary filtering

  • Filters use employer-advertised annual base only.
  • USD is converted with the snapshot usd_to_cad rate for comparison; employer currency stays on the job.
  • Missing / non-annual pay is undisclosed — never estimated.
  • Non-positive salary_min / salary_max values are ignored.

Dataset freshness

Responses include dataset_id and generated_at. /api/v1/health reports ok or degraded when age exceeds stale_after_hours (default 48). Jobs expose last_verified. 

curl -sS https://api.githired.ca/api/v1/health | jq .

Rate limits

Approximately 120 requests / minute / IP. Burst abuse may receive HTTP 429.

Dataset coverage

The API serves a curated snapshot of Canada-eligible engineering roles (hard-filter PASS + ELIGIBLE + direct apply URL). The snapshot is capped for Worker bundle size and freshness; see /api/v1/stats for the live count. The website shortlist uses the same eligibility rules.

MCP

AI clients can use the same dataset over MCP at https://api.githired.ca/mcp. See Agent docs for Cursor one-click install and Claude / ChatGPT setup.
