GitHired REST API

Query Canada-eligible technology jobs discovered from employer ATS boards. Free to use. No authentication for normal search traffic.

Base URL

https://api.githired.ca

OpenAPI: /openapi.json · MCP: /agents

Endpoints

  • GET /api/v1/jobs — search & filter
  • GET /api/v1/jobs/{id} — job detail + description excerpt
  • GET /api/v1/companies — employers + active counts
  • GET /api/v1/stats — dataset aggregates
  • GET /api/v1/health — service + freshness
  • POST /api/v1/match — deterministic profile match (not stored)

Example

curl -s 'https://api.githired.ca/api/v1/jobs?q=data%20engineer&remote=true&salary_min=150000&limit=10' | jq .

Query parameters

q, location, province, remote, work_mode, salary_min, salary_max, salary_disclosed, seniority, company, sort (relevance|salary|freshness), limit (max 50), cursor.

Salary filtering

Filters apply to employer-advertised annual base pay only (CAD/USD). USD amounts are converted with the snapshot usd_to_cad rate for comparison. Missing or non-annual pay is treated as undisclosed — never estimated.

Rate limits

Approximately 120 requests / minute / IP. Burst abuse may receive HTTP 429.

Dataset freshness

Every response includes dataset_id and generated_at. /api/v1/health reports whether the dataset is fresh or stale. Jobs include last_verified timestamps.

MCP

Compatible AI clients can use the remote MCP server at https://api.githired.ca/mcp. See Agent docs.
