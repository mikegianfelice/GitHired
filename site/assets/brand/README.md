# GitHired brand assets (site)

Production icons and the vector master for [githired.ca](https://githired.ca).

- **Master:** `githired-g-master.svg`
- **Live mark:** `githired-mark.svg` (nav + wordmark CSS)
- **Icons:** `favicon.ico`, `favicon-32x32.png`, `apple-touch-icon.png`, `android-chrome-*.png`

Palette: green `#65E52B`, hover `#43C91E`, deep `#168A43`, background `#FFFFFF`, surface `#F8FAF8`, text `#0B0F14`, muted `#647067`, border `#E3EAE2`.

See `USAGE.md` for roles. Older kit exports are archived in `assets/githired_brand_assets.zip`.
