# GitHired site brand assets

## Source of truth

`githired-g-master.svg` — vector G (paths + gradients).  
Website mark: `githired-mark.svg` (same art; slightly taller viewBox to avoid bottom clipping).

Nav uses the SVG mark plus a CSS wordmark (see `site/styles.css`), not a raster lockup.

## Production files

| Asset | Role |
| --- | --- |
| `githired-mark.svg` | Header mark |
| `favicon.ico`, `favicon-32x32.png`, `apple-touch-icon.png` | Browser icons |
| `android-chrome-192x192.png` / `512x512.png` | PWA / Open Graph |

Repo-level copies of the masters also live under `assets/brand/`. Full kit archive: `assets/githired_brand_assets.zip`.
