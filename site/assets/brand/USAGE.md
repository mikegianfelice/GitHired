# GitHired site brand assets

## Source of truth

`githired-g-master.svg` — manually reconstructed vector G (paths + gradients).  
Website mark: `githired-mark.svg` (same art; slightly taller viewBox to avoid bottom clipping).

## Production files

| Asset | Role |
| --- | --- |
| `githired-logo-light.svg` / `.png` / `.webp` | Desktop nav lockup (SVG preferred) |
| `githired-logo-dark.svg` / `.png` / `.webp` | Dark-background lockup |
| `githired-mark.svg` + `githired-mark-{128,256,512}.png` | Compact/mobile mark |
| `favicon.ico`, `favicon-32x32.png`, `apple-touch-icon.png` | Icons from SVG |
| `android-chrome-192x192.png` / `512x512.png` | PWA icons from SVG |

Older WebP mark assets remain as `<picture>` fallbacks.
