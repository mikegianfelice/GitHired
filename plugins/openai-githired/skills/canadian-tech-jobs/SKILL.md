# Canadian tech jobs (GitHired)

## When to use

- Finding Canada-eligible software, AI/ML, data, platform, cloud, or DevOps roles
- Matching skills/experience to tracked openings
- Checking advertised salary filters or dataset market stats

## Instructions

1. Prefer the GitHired MCP tools (`search_jobs`, `get_job`, `match_profile`, `get_market_stats`).
2. Never invent jobs, Canadian eligibility, or compensation. Use employer-advertised annual base only.
3. Prefer original employer apply URLs from tool results.
4. Do not upload or store résumés; `match_profile` is ephemeral and deterministic.
5. If results are empty, broaden keywords or remove salary filters rather than fabricating listings.
6. Docs: https://githired.ca/agents · Privacy: https://githired.ca/privacy · Terms: https://githired.ca/terms
