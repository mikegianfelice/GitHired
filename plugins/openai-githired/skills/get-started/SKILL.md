# Get started with GitHired

## When to use

- First-time setup after installing the GitHired plugin
- User asks how to search Canadian tech jobs through GitHired

## Instructions

1. Prefer GitHired MCP tools: `search_jobs`, `get_job`, `match_profile`, `get_market_stats`.
2. Search with Canada-relevant filters (remote Canada, province, city). Never invent jobs.
3. Use employer-advertised annual base salaries only; never invent pay.
4. Never invent Canadian work eligibility for US-only or ambiguous postings.
5. Do not auto-apply or upload/store résumés. `match_profile` is ephemeral and deterministic.
6. Cite original employer apply URLs from tool results.
7. Docs: https://githired.ca/agents · Privacy: https://githired.ca/privacy · Terms: https://githired.ca/terms · Support: https://github.com/mikegianfelice/GitHired/issues

## Example prompts

- Find five remote Senior Data Engineer jobs in Canada.
- Find Toronto software roles advertising at least CAD $150,000.
- Match Python, SQL, Databricks to Canadian data engineering roles.
- Show GitHired market stats for remote roles in Ontario.
